# docs/

Carpeta de **documentacion semanal** del proyecto ObsidiantFIT.

## Como documentar

Crear un archivo por semana con el formato `semana-XX.md`:

```
docs/
|-- semana-01.md    <- Semana del 20/04 al 26/04
|-- semana-02.md    <- Semana del 27/04 al 03/05
|-- semana-03.md    <- Semana del 04/05 al 10/05
`-- ...
```

## Template de cada semana

```markdown
# Semana XX — [rango de fechas]

## Objetivo de la semana
Breve descripcion de en que se enfoco la semana.

## Lo que se hizo
- Item 1
- Item 2

## Dependencias instaladas
- `nombre-paquete@version` — para que sirve

## Archivos creados/modificados
- `ruta/al/archivo.ts` — que hace

## Problemas encontrados y soluciones
- Problema: ...
  Solucion: ...

## Objetivo de la proxima semana
- ...
```
