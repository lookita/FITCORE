# fundamentos-ts/

Carpeta de ejercicios de **Fase 1** del roadmap: fundamentos de TypeScript.

## Contenido esperado

Ejercicios progresivos de TypeScript puro, sin frameworks:

- `01-tipos-basicos.ts` — tipos primitivos, type aliases, unions
- `02-interfaces.ts` — interfaces, optional props, readonly
- `03-funciones.ts` — tipado de funciones, overloads
- `04-genericos.ts` — generics, constraints
- `05-enums.ts` — enums numericos y de string
- `06-utility-types.ts` — Partial, Required, Pick, Omit, Record

## Como ejecutar un ejercicio

```bash
cd Back/fundamentos-ts
npx ts-node nombre-del-archivo.ts
```

## Notas

Estos archivos son de **practica y aprendizaje**. No forman parte del build de produccion de NestJS.
