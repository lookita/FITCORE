# Introducción a Decoradores — Stickers con Superpoderes

### ¿Qué es esto? (La analogía) 🏷️✨
Imagina que tienes una botella de agua común. Si le pegas un sticker que dice "**¡Agua Energética!**", la botella sigue siendo de agua, pero ahora tiene un "poder" o una etiqueta especial. Los **Decoradores** son esos stickers (`@`) que le pegas a tus clases o funciones para darles habilidades extra sin tener que cambiar el código de adentro.

### ¿Cuándo lo uso en ObsidiantFit? 🎀
- Para decir: "Esta clase es una herramienta que se puede inyectar en otros lados" (`@Injectable`).
- Para marcar qué funciones necesitan que el usuario haya pagado la suscripción (`@Auth`).

### El Truco del Experto 💡
Los decoradores son como la magia negra de TypeScript: muy poderosos pero hay que usarlos con cuidado. Se usan muchísimo en frameworks como **NestJS**, así que acostúmbrate a ver el símbolo `@` por todos lados.
