# Introducción a Tipos — El Inspector de Calidad

### ¿Qué es esto? (La analogía) 👮‍♂️🏗️
Imagina que estás construyendo un gimnasio y llega un camión con materiales. El **Inspector de Calidad (TypeScript)** revisa cada caja: "Esto es cemento, va para las paredes", "Esto es un espejo, va para el salón". Si intentas usar un espejo para construir una columna, el inspector te detiene antes de que el edificio se caiga. Los Tipos son esas etiquetas que le dicen al inspector qué es cada cosa.

### ¿Cuándo lo uso en ObsidiantFit? 🧱
- Para asegurar que una variable de `precio` nunca reciba un texto como `"Gratis"`.
- Para definir exactamente qué datos debe tener un `Usuario`.
- Para evitar errores tontos de "dedazo" (escribir mal una palabra).

### ¿Por qué son importantes?
Sin tipos, tu código es como un gimnasio a oscuras: puedes tropezar con cualquier cosa. Con tipos, las luces están encendidas y TypeScript te avisa: "¡Cuidado! Estás intentando sumar un número con un emoji".

### El Truco del Experto 💡
Los tipos no son para molestar, son para **ayudarte**. Al principio parece que escribes más código, pero a la larga te ahorran horas de buscar errores que el "Inspector" habría detectado en un segundo.
