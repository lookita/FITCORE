# 7. Decoradores — ¡Ponle Stickers a tu Código!

---

## 🧠 ¿Qué es un Decorador? (ELI10)

Imagina que tienes una **Mancuerna**. 
Un decorador es como un **Sticker mágico** que le pegas a la mancuerna. El sticker no cambia qué es la mancuerna, pero le da "superpoderes" o hace algo especial cuando alguien la toca.

- En TypeScript, los decoradores empiezan con una arroba (`@`).
- Sirven para **anotar** o **modificar** clases y métodos de forma automática.

---

## 🛠️ Nivel 1: El Decorador de Clase (Fácil)

Vamos a crear un sticker que simplemente diga "Esta clase es para ObsidiantFit".

```typescript
function EsDeObsidiantFit(constructor: Function) {
  console.log("--- Sticker pegado en la clase ---");
  constructor.prototype.empresa = "ObsidiantFit Corp";
}

@EsDeObsidiantFit
class Ejercicio {
  constructor(public nombre: string) {}
}

const ex = new Ejercicio("Dominadas");
console.log((ex as any).empresa); // "ObsidiantFit Corp"
```

---

## 🏗️ Nivel 2: Decorador de Método (Intermedio)

Este sticker vigila cuando alguien usa una función.

```typescript
function Log(target: any, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value; // Guardamos la función original

  descriptor.value = function (...args: any[]) {
    console.log(`📢 Ejecutando: ${key} con datos: ${args}`);
    return original.apply(this, args); // Ejecutamos la función real
  };
}

class Usuario {
  @Log // Pegamos el sticker de Log
  entrenar(minutos: number) {
    console.log(`Entrenando por ${minutos} min.`);
  }
}

const u = new Usuario();
u.entrenar(30); 
// Imprime:
// 📢 Ejecutando: entrenar con datos: 30
// Entrenando por 30 min.
```

## 🚀 Nivel 3: Ejemplo Real en NestJS (Complejo)

En el backend que vas a usar, los decoradores están por todos lados. No necesitas crearlos, ¡solo usarlos!

```typescript
@Controller('usuarios') // Sticker que dice: "Esto maneja rutas de usuarios"
class UsuariosController {

  @Get() // Sticker que dice: "Esta función se activa cuando alguien entra a la web"
  obtenerTodos() {
    return ["Lucas", "Mateo", "Santi"];
  }

  @Post() // Sticker que dice: "Esto es para crear un usuario nuevo"
  crear(@Body() datos: any) {
    console.log("Guardando...");
  }
}
```

---

## 🔑 Resumen para recordar:

1.  **Anotaciones**: El decorador "etiqueta" el código para que el sistema sepa qué hacer con él.
2.  **Menos código**: En vez de escribir mucha lógica aburrida, pegas un sticker `@` y ya está.
3.  **Experimental**: Para usar decoradores, tienes que activar una opción en el archivo de configuración de TypeScript (`experimentalDecorators: true`).

---

## 💡 ¿Por qué los amamos?

Porque hacen que el código sea **declarativo**. En vez de explicar CÓMO hacer las cosas, solo dices QUÉ es cada cosa pegando una etiqueta. "Esto es un Controlador", "Esto es una Ruta", "Esto es un Parámetro".
