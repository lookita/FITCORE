# 6. Getters y Setters — Los Guardias de Propiedades

---

## 🧠 ¿Qué son? (ELI10)

Imagina que tienes una **Balanza** en tu gimnasio. 
No quieres que nadie pueda poner un peso negativo (como `-50 kg`) porque eso es imposible.

Los **Getters** y **Setters** son como guardias que cuidan una propiedad privada:
- **Getter**: El guardia que te deja "ver" el valor (pero quizás te lo muestra de forma distinta).
- **Setter**: El guardia que revisa si el nuevo valor que quieres poner es correcto antes de guardarlo.

---

## 🛠️ Nivel 1: El guardia que vigila (Fácil)

Usamos las palabras `get` y `set`.

```typescript
class Balanza {
  private _peso: number = 0; // Usamos '_' para la propiedad privada

  // SETTER: Vigilante al entrar
  set peso(valor: number) {
    if (valor < 0) {
      console.log("❌ ¡Error! El peso no puede ser negativo.");
      return;
    }
    this._peso = valor;
  }

  // GETTER: Vigilante al salir
  get peso(): number {
    return this._peso;
  }
}

const miBalanza = new Balanza();
miBalanza.peso = 75;  // ✅ Usa el setter
console.log(miBalanza.peso); // ✅ Usa el getter -> 75

miBalanza.peso = -10; // ❌ Imprime error y no cambia el valor
```

---

## 🏗️ Nivel 2: Transformando datos (Intermedio)

A veces el Getter te devuelve el dato de una forma más bonita.

```typescript
class Atleta {
  constructor(public nombre: string, public apellido: string) {}

  // Getter para el nombre completo
  get nombreCompleto(): string {
    return `${this.nombre} ${this.apellido}`;
  }
}

const p = new Atleta("Lucas", "Pérez");
console.log(p.nombreCompleto); // "Lucas Pérez"
```

---

## 🚀 Nivel 3: Ejemplo Maestro en ObsidiantFit

Vamos a controlar el **Nivel** de un usuario para que no pase de 100.

```typescript
class PerfilUsuario {
  private _nivel: number = 1;

  get nivel() {
    return this._nivel;
  }

  set nivel(nuevoNivel: number) {
    if (nuevoNivel > 100) {
      console.log("¡Wow! Nivel máximo alcanzado (100).");
      this._nivel = 100;
    } else if (nuevoNivel < 1) {
      this._nivel = 1;
    } else {
      this._nivel = nuevoNivel;
    }
  }
}

const user = new PerfilUsuario();
user.nivel = 150; // El setter lo frena en 100
console.log(user.nivel); // 100
```

---

## 🔑 Reglas de Oro:

1.  **Sin paréntesis**: Aunque parecen funciones, se usan como si fueran variables normales (`user.nivel = 5` en vez de `user.nivel(5)`).
2.  **Protección**: Siempre usa una variable `private` (normalmente con un guion bajo `_nombre`) para guardar el dato real.
3.  **Solo lectura**: Si creas un `get` pero NO un `set`, la propiedad se vuelve automáticamente de solo lectura.

---

## 💡 ¿Por qué usarlos?

Para que tu código sea **robusto**. Si dejas que cualquiera cambie cualquier dato, tu programa se llenará de errores. Con Getters y Setters, tú tienes el control total.
