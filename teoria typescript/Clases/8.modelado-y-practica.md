# 8. Modelado de Clases — Diseñando tu propio Gimnasio

---

## 🧠 ¿Cómo pensar en Clases? (ELI10)

Cuando vayas a crear una parte de ObsidiantFit, no empieces a escribir código de una. 
Primero, **cierra los ojos** e imagina qué es cada cosa.

Hazte estas dos preguntas mágicas:
1.  **¿Qué ES?** (Estas serán las **Propiedades** / Datos).
2.  **¿Qué HACE?** (Estos serán los **Métodos** / Funciones).

---

## 🛠️ Nivel 1: El Objeto Inanimado (Fácil)

Vamos a modelar una **Rutina**.

**¿Qué ES una Rutina?**
- Tiene un `nombre`.
- Tiene una `dificultad`.
- Tiene una lista de `ejercicios`.

```typescript
class Rutina {
  constructor(
    public nombre: string,
    public dificultad: "fácil" | "media" | "difícil",
    public ejercicios: string[]
  ) {}
}
```

---

## 🏗️ Nivel 2: Agregando Vida (Intermedio)

Ahora vamos a modelar el **Cronómetro** de la app.

**¿Qué ES?**
- Tiene un `tiempoActual` (segundos).
- Tiene un estado `estaCorriendo`.

**¿Qué HACE?**
- Puede `iniciar()`.
- Puede `detener()`.
- Puede `reiniciar()`.

```typescript
class Cronometro {
  private _segundos: number = 0;
  private _intervalo: any;

  iniciar() {
    this._intervalo = setInterval(() => {
      this._segundos++;
      console.log(`Tiempo: ${this._segundos}s`);
    }, 1000);
  }

  detener() {
    clearInterval(this._intervalo);
  }

  reiniciar() {
    this._segundos = 0;
  }
}
```

## 🚀 Nivel 3: El Sistema Completo (Complejo)

Vamos a conectar todo. Un **Entrenador** que asigna una **Rutina** a un **Atleta**.

```typescript
class Atleta {
  public rutinaAsignada?: string;
  constructor(public nombre: string) {}
}

class Entrenador {
  constructor(public nombre: string, public especialidad: string) {}

  asignarRutina(alumno: Atleta, nombreRutina: string) {
    alumno.rutinaAsignada = nombreRutina;
    console.log(`👨‍🏫 ${this.nombre} le dio la rutina "${nombreRutina}" a ${alumno.nombre}`);
  }
}

// En acción:
const coach = new Entrenador("Coach Martínez", "Calistenia");
const alumno = new Atleta("Lucas");

coach.asignarRutina(alumno, "Fase 1: Fuerza Básica");
```

---

## 🔑 Consejos para Diseñar como un Pro:

1.  **S.O.L.I.D. (Simplificado)**: Cada clase debe hacer **una sola cosa**. No crees una clase `Gimnasio` que maneje pagos, rutinas, limpieza, música y comida. Crea una clase para cada cosa.
2.  **Privacidad primero**: Empieza poniendo todo como `private`. Si después te das cuenta de que necesitas verlo desde afuera, cámbialo a `public`. ¡Es más seguro cerrar la puerta y abrirla después que dejarla abierta siempre!
3.  **Usa Nombres Claros**: En vez de `class C`, usa `class Cronometro`. En vez de `p`, usa `puntosDeExperiencia`. Tu "yo del futuro" te lo agradecerá.
