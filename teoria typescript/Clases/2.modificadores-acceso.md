# 2. Modificadores de Acceso — Quién Puede Tocar Mis Cosas

---

## 🧠 El Problema: El Usuario Travieso

Imagina que tienes la clase `Atleta` y guardas su **XP**. 
Si todo es público, cualquier persona podría hacer trampa:

```typescript
const cheto = new Atleta("Cheto");
cheto.xpTotal = 9999999; // ❌ ¡NO! Esto es trampa.
```

Para evitar esto, usamos "Candados". TypeScript tiene 3 candados principales:

---

## 📍 Nivel 1: `public` (La puerta abierta) 🔓

Si no dices nada, todo es público. Cualquiera puede verlo y cambiarlo desde afuera.

```typescript
class Gimnasio {
  public nombre: string = "Obsidiant Gym";
}

const gym = new Gimnasio();
gym.nombre = "Gym de Barrio"; // ✅ Se puede cambiar sin problemas
```

---

## 📍 Nivel 2: `private` (El diario íntimo) 🔒

Es el candado más fuerte. **Nadie** puede verlo ni tocarlo, excepto la propia clase. Ni siquiera tus hijos pueden entrar aquí.

```typescript
class Usuario {
  public nombre: string;
  private contrasena: string; // 🔒 Candado puesto

  constructor(nombre: string, clave: string) {
    this.nombre = nombre;
    this.contrasena = clave;
  }

  // Solo yo puedo ver mi contraseña para validarla
  login(intento: string) {
    return this.contrasena === intento; // ✅ Adentro de la clase sí funciona
  }
}

const lucas = new Usuario("Lucas", "perrito123");
console.log(lucas.nombre);     // ✅ "Lucas"
// console.log(lucas.contrasena); // ❌ Error: "¡Atrás! Esto es privado"
```

---

## 📍 Nivel 3: `protected` (La herencia familiar) 👤

Es un candado especial. No deja entrar a extraños, pero **sí deja entrar a tus hijos** (clases que heredan de ti).

```typescript
class Equipamiento {
  protected salud: number = 100; // Solo yo y mis hijos
}

class Mancuerna extends Equipamiento {
  golpear() {
    this.salud -= 5; // ✅ OK: Como es hijo, puede tocar la salud
  }
}

const m = new Mancuerna();
// console.log(m.salud); // ❌ Error: Yo no soy familia, no puedo entrar
```

---

## 📍 Nivel 4: `readonly` (La vitrina del trofeo) ❄️

Puedes ver el valor, pero **nunca** cambiarlo después de que se creó. Es como una placa de bronce grabada.

```typescript
class Logro {
  public readonly fecha: string;

  constructor() {
    this.fecha = "12/05/2026"; // Se graba al nacer
  }
}

const miLogro = new Logro();
console.log(miLogro.fecha); // ✅ "12/05/2026"
// miLogro.fecha = "ayer";   // ❌ Error: "No puedes cambiar la historia"
```

## 🚀 El Truco Maestro: El Atajo de Constructor

En ObsidiantFit vamos a usar mucho este atajo para escribir menos código. Puedes crear la propiedad e inicializarla **en la misma línea** donde recibes los datos.

### ❌ Forma aburrida y larga:
```typescript
class Rutina {
  public nombre: string;
  constructor(nombre: string) {
    this.nombre = nombre;
  }
}
```

### ✅ Forma Pro (Atajo de TypeScript):
```typescript
class Rutina {
  // Al poner 'public' o 'private' aquí, TypeScript hace todo solo
  constructor(public nombre: string) {}
}

const r = new Rutina("Pecho y Tríceps");
console.log(r.nombre); // ✅ Funciona igual y escribiste 4 líneas menos
```

---

## 📊 Tabla de Decisión Rápida

| Si quieres que... | Usa... |
|---|---|
| Todos lo vean y lo cambien | `public` |
| Solo tú lo veas (máximo secreto) | `private` |
| Solo tú y tus hijos lo vean | `protected` |
| Se vea pero NO se cambie | `readonly` |
| Sea secreto y NO se cambie | `private readonly` |
