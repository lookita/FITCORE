# 1. Introducción a Clases — El Molde Maestro de ObsidiantFit

---

## 🧠 ¿Qué es una Clase? (Explicado a un niño de 10 años)

Imagina que quieres fabricar **Mancuernas** para tu gimnasio. 
No vas a inventar cómo es una mancuerna cada vez que necesites una. En lugar de eso, haces un **molde** de acero.

Ese molde dice:
1. Todas las mancuernas tienen un **Peso** (número).
2. Todas tienen un **Material** (texto).
3. Todas pueden **Pesarse** (una acción).

- **La Clase** es el **MOLDE**. No es una mancuerna real, es la idea de cómo debe ser una.
- **La Instancia (u Objeto)** es la **MANCUERNA REAL** que sale del molde.

---

## 🛠️ Nivel 1: Mi primera clase (Muy fácil)

Vamos a crear el molde para un ejercicio simple.

```typescript
class EjercicioSimple {
  // 1. Propiedades (Lo que el ejercicio TIENE)
  nombre: string = "Salto";
  puntosXP: number = 10;

  // 2. Métodos (Lo que el ejercicio HACE)
  completar() {
    console.log(`¡Hiciste un ${this.nombre}! Ganaste ${this.puntosXP} XP.`);
  }
}

// Fabricamos un ejercicio real usando el molde
const miSalto = new EjercicioSimple();

// Usamos el ejercicio
miSalto.completar(); // Imprime: ¡Hiciste un Salto! Ganaste 10 XP.
```

## 🏗️ Nivel 2: Fabricando cosas distintas con el mismo molde (Intermedio)

¿Qué pasa si quiero que cada ejercicio tenga su propio nombre? Para eso usamos el **Constructor** (la máquina que rellena el molde).

```typescript
class Ejercicio {
  nombre: string;
  xp: number;

  // El constructor es la función que se ejecuta cuando haces "new"
  constructor(nombreRecibido: string, xpRecibida: number) {
    this.nombre = nombreRecibido;
    this.xp = xpRecibida;
  }

  mostrarInfo() {
    console.log(`Ejercicio: ${this.nombre} | Recompensa: ${this.xp} XP`);
  }
}

// Ahora podemos crear ejercicios diferentes con el mismo molde:
const flexion = new Ejercicio("Flexiones", 15);
const sentadilla = new Ejercicio("Sentadillas", 20);

flexion.mostrarInfo();    // Ejercicio: Flexiones | Recompensa: 15 XP
sentadilla.mostrarInfo(); // Ejercicio: Sentadillas | Recompensa: 20 XP
```

## 🚀 Nivel 3: El Molde de un Usuario (Complejo)

Vamos a crear algo que use datos de ObsidiantFit de verdad. Un usuario que sube de nivel.

```typescript
class Atleta {
  nombre: string;
  nivel: number = 1;
  xpTotal: number = 0;

  constructor(nombre: string) {
    this.nombre = nombre;
  }

  ganarXP(cantidad: number) {
    this.xpTotal += cantidad;
    console.log(`${this.nombre} ganó ${cantidad} XP. Total: ${this.xpTotal}`);

    // Si llega a 100 XP, sube de nivel
    if (this.xpTotal >= 100) {
      this.subirNivel();
    }
  }

  subirNivel() {
    this.nivel++;
    this.xpTotal = 0; // Reiniciamos el XP para el siguiente nivel
    console.log(`¡Felicidades ${this.nombre}! Ahora eres Nivel ${this.nivel} 🏆`);
  }
}

const lucas = new Atleta("Lucas");

lucas.ganarXP(50); // Lucas ganó 50 XP. Total: 50
lucas.ganarXP(60); // Lucas ganó 60 XP. Total: 110
                   // ¡Felicidades Lucas! Ahora eres Nivel 2 🏆
```

---

## 🔑 Conceptos que tienes que grabar en tu mente:

1.  **`class`**: La palabra para empezar a crear el molde.
2.  **`new`**: La palabra mágica para "fabricar" un objeto real a partir del molde.
3.  **`this`**: Significa "yo mismo" o "esta clase". Se usa para que la clase pueda acceder a sus propias propiedades (ej: `this.nombre`).
4.  **`constructor`**: El lugar donde le pasas los datos iniciales al objeto cuando nace.

---

## 💡 ¿Por qué usamos esto en ObsidiantFit?

Imagina que tienes 1.000 usuarios. No quieres escribir manualmente el código de "subir nivel" para cada uno de los 1.000. 
Escribes el código **UNA VEZ** en la clase `Atleta`, y los 1.000 usuarios lo heredan automáticamente. ¡Es como tener un ejército de clones que saben qué hacer!
