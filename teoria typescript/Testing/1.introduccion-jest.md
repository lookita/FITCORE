# Jest — El Juez de ObsidiantFit 🃏⚖️

---

## 🧠 ¿Qué es Jest? (ELI10)

Imagina que en **ObsidiantFit** prometemos que si un usuario hace 10 flexiones, quema 50 calorías. ¿Cómo estamos seguros de que el código no tiene un error y le da 500 calorías por error?

**Jest** es un programa que ejecuta tu código automáticamente y verifica que los resultados sean los correctos. Es como un **entrenador personal** que te mira mientras haces el ejercicio y te dice: "No, eso no contó, hazlo de nuevo".

---

## 🏗️ La Estructura de un Test (El "Juicio")

Un archivo de test en Jest se divide en tres partes principales que se leen casi como inglés:

1.  **`describe`**: Agrupa un conjunto de pruebas (ej: "Pruebas del Calculador de Calorías").
2.  **`it`** o **`test`**: Una prueba individual (ej: "debería devolver 50 para 10 flexiones").
3.  **`expect`**: La verificación real (el momento de la verdad).

```typescript
describe('Calculador de Calorías', () => {
  
  it('debería calcular correctamente 10 flexiones', () => {
    const resultado = calcularCalorias("flexiones", 10);
    
    // El momento del juicio:
    expect(resultado).toBe(50); 
  });

});
```

## 🔍 Los Matchers (Los Criterios del Juez)

Jest tiene diferentes formas de comparar resultados:

- **`.toBe(x)`**: Para valores simples (números, strings). Exactamente igual.
- **`.toEqual(obj)`**: Para objetos o arrays. Verifica que el contenido sea el mismo.
- **`.toContain(item)`**: Para ver si un ejercicio está en una lista.
- **`.toThrow()`**: Para verificar que el código lanza un error si le pasamos datos basura.

```typescript
it('debería añadir el ejercicio a la rutina', () => {
  const rutina = ['Sentadillas'];
  rutina.push('Plancha');

  expect(rutina).toContain('Plancha'); // ✅ Pasa
  expect(rutina).toHaveLength(2);      // ✅ Pasa
});
```

## ⏱️ El Ciclo de Vida (Limpiando el Gimnasio)

A veces necesitas preparar algo antes de cada test (como limpiar las pesas) y recoger todo al terminar.

- **`beforeEach`**: Se ejecuta **antes de cada** `it`. Ideal para resetear variables.
- **`afterEach`**: Se ejecuta **después de cada** `it`.
- **`beforeAll` / `afterAll`**: Se ejecutan solo una vez al principio o al final de todo el archivo.

```typescript
describe('Sesión de Entrenamiento', () => {
  let sesion;

  beforeEach(() => {
    sesion = new Sesion(); // Creamos una sesión nueva para cada test
    console.log("Gimnasio limpio para el siguiente test");
  });

  it('debería empezar con 0 puntos', () => {
    expect(sesion.puntos).toBe(0);
  });
});
```

## 🚀 ¿Por qué Jest es el rey en NestJS?

1.  **Velocidad:** Ejecuta los tests en paralelo.
2.  **Zero Config:** Viene listo para usar cuando creas un proyecto de NestJS.
3.  **Mocks Integrados:** Como vimos en el archivo de [Mocks](../Arquitectura/testing-y-mocks.md), Jest tiene a `jest.fn()` para crear espías fácilmente.
4.  **Snapshot Testing:** Puede "sacar una foto" a tu respuesta de la API y avisarte si un solo punto cambió en el futuro.

---

## 🔑 Resumen Maestro

- **describe**: "La categoría" (ej: Pecho).
- **it**: "El ejercicio" (ej: Press banca).
- **expect**: "La técnica" (ej: ¿Bajó la barra hasta el pecho?).
- **toBe / toEqual**: "El peso" (ej: ¿Eran 100kg?).
